  | 肋骨在中段"断开" | 肋软骨配色比骨色暗，且与肋骨平口相接 | 软骨↔肋骨最近距离 0.05–0.55 mm（中位 0.12），网格平均边长 3.96 mm——**贴着的** |
  | 脊柱每节"崩口" | 椎间盘与椎体**互相穿插** | 2 mm 内的盘顶点 44% 在椎骨内部，中位穿插 0.11 mm、最深 1.76 mm |

  **通则：BP3D 的每个结构是独立重建的，交界处既不是共面也不是留缝，而是互相穿插。**
  凡是两个结构挨着的地方都要按这个假设处理，别指望它们严丝合缝。

  修法与它的边界：肋软骨改配色（暗蓝灰 → 比骨头更亮的珠光蓝白）就够了。
  椎间盘沿法线内缩 0.5 mm + 配色靠近骨色，**只是压低而不是消除**——
  要压干净得内缩 1.5 mm，那会削掉两成盘高。彻底解是布尔减法，记在待定里。
  另外：一开始我怀疑"右脚外翻 90° 像脱位"，拍了纯骨骼特写之后**证伪**——
  两只脚完整且正常，之前那个印象是斜机位造成的。**别把猜测写进结论。**

- 2026-08-21 · **对标 Complete Anatomy / ZygoteBody：差距在数据，不在引擎** ·
  人类问"更专业的版本或 APP 是不是还有另一条技术路线"。查了一圈，结论是
  **换引擎解决不了我们的问题**：

  | | 引擎 | 结构数 | 资产可用性 |
  |---|---|---|---|
  | Complete Anatomy（Elsevier） | 原生自研，跑在 **Metal** 上，不是 Unity | **13,000+** | 全闭源商业，订阅制，**一件都不能用** |
  | ZygoteBody | WebGL（与我们同族） | 未公开 | 模型是 Zygote Media Group 的商业授权内容，按件/按集收版税或订阅，**不能用** |
  | HyiBody | three.js WebGL2 + BatchedMesh | 235（BP3D 2,234 件里挑的） | CC BY 4.0，全部自有流水线 |

  **ZygoteBody 的查看器代码倒是开源的**：Google Body 关站后核心代码以
  `open-3d-viewer` 发布，Apache 2.0。但那是 2012 年的 WebGL 1 代码，
  我们现在这套（r185 + 合批 + 41 次绘制调用）已经越过它了，**没有移植价值**，
  值得看的只有它的"分层滑块 + 即时搜索"交互，而那两样我们本来就有。

  所以"更专业"的排序是 **数据 > 内容 > 渲染**：Complete Anatomy 的
  13,000 件是逐件手工建模 + 手绘贴图，换成 Unity 或 Metal 也变不出一件来。
  我们这一轮已经自己撞过这堵墙——皮肤 203,382 面就是 BP3D 原生全部、且没有 UV，
  再怎么写着色器也上不去。

  **搜索里冒出来的两个要当心**：Open3DModel（CC BY-SA）与 Z-Anatomy 都在
  ATTRIBUTION 的禁用名单里，别因为搜到就用。另外有个 GitHub 镜像把 BodyParts3D
  标成 "CC BY-SA 2.1 Japan"，与我们记录的 CC BY 4.0 不一致——**以官方许可证页
  与 `docs/licenses/` 里的 PDF 快照为准**（`pipeline/config/sources.yaml` 里存了链接）。
  真要较真时请人类核一次。

  现在的顺纹方向一律取世界 Z（身体长轴），对股四头肌、竖脊肌这类是对的，

  存一个方向向量，而**合批下每实例的通道已经被"颜色 + 不透明度"占满**

  先看看按长轴出纹的观感够不够；不够再动这一层。

- **动态分辨率（帧率兜底）**（2026-08-21，等人类真机结果再定）。全量之后手机默认档
  在肌肉层是 **724 万三角面/帧**，是 B 计划的两倍，而"中端安卓 30 fps"从没验过。
  现在的画质分档（low / medium / high）只切后处理与阴影，**不动渲染分辨率**——
  而 CPU/GPU 的像素开销恰恰是分辨率的平方项。做法是量帧时间，超阈值就把
  `renderer.setPixelRatio` 往下调（1.0 → 0.75 → 0.5），回落了再调回来。
  好处不只在手机：云端软件渲染的 e2e 也会跟着快起来（现在约 1.2 秒一帧，
  整套跑 40 多分钟）。
  **建议先等真机结果**：如果人类的手机本来就顺，这就是白加一层复杂度和一个
  "画面会自己变糊"的新观感问题；如果不顺，它比砍面数更划算——砍面数是所有人
  都变差，降分辨率只有跑不动的机器才变差。

- **HRA 器官要不要也走全量**（2026-08-21，等人类拍板）。这轮只把 BP3D 拉满，
